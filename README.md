# Mood-Based-Recommendation-System
Mood-Based-Recommendation-System. It checks the user mood and recommend them movies music books or series as well as in preffered language hindi or english according to user choice
A Python-based recommendation system that suggests movies, music, books, and web series based on the user's mood and preferred language.
## Features
* Mood-based recommendations
* Supports Hindi and English preferences
* Recommends content across multiple categories
* Simple and user-friendly interface
* 
## Technologies Used

* Python

## How to Run

1. Download the project files.
2. Run the main Python file.
3. Select your mood and preferred language.
4. View personalized recommendations.
